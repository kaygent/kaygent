Terminal kanban · agent handoff

Your task board,
wired to your agents.

Kaygent is a keyboard-first kanban board that lives in your terminal. Move a task to Active and it opens a tab in your terminal, runs your agent, and keeps the session attached. Pause, resume, complete — the terminal follows.

Workflow

Built around the handoff.

Kaygent is not just another todo list. Each column has a job, and your terminal follows along.

↗

Agent handoff

Moving to Active launches your command in a terminal tab or window and saves the session. Enter focuses it; Completed closes it.

⇄

Task sources

Pull items from GitHub, Jira, Slack, Teams, Outlook, Gmail, or any command that prints JSON. Stable ids and deduplication are built in.

⌂

Local-first

Your board and config are plain JSON on disk. No account, no sync service, no network calls unless one of your sources makes them.

⌘

Terminal-native

Herdr, tmux, WezTerm, Windows Terminal, a process fallback, or your own custom spawn, focus, and close commands.

Task sources

One board,
every inbox.

A source is a command. Whatever it prints — messages or full tasks — becomes a card in New. Configure a refresh interval per source, or keep it manual. Foreground sources open a terminal tab for interactive auth and close it when they finish.

  • GitHub issues
  • Jira
  • Slack
  • Teams
  • Outlook
  • Gmail
  • Any JSON command
config.jsontask source
{
  "taskSources": [
    {
      "sourceName": "github",
      "command": "gh issue list --json number,title,url,labels --limit 50",
      "refreshMinutes": 15,
      "runMode": "background"
    }
  ]
}

Install

Clone, install, clear the board.

Prebuilt 64-bit Windows and Linux binaries are available on GitHub Releases. Building from source needs Node.js 22+ and npm.

Download binaries Read the docs View source

cd kaygent
npm install
